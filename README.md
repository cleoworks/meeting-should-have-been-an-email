Entry for the make.fun bounty **The Meeting That Should Have Been an Email**: one
funny single-line joke about a meeting that should have been an email, under
200 characters.

The program (`main.py`, Python 3, no dependencies) writes the joke to
`/output/entry.txt`:

> The email was two sentences; the meeting added a third, then spent an hour arguing about the comma.

99 characters, plain ASCII. Run it with `python3 main.py`.
